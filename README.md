## 部署

使用 GitHub 網頁版的 `uploading an existing file`，將本資料夾**裡面的所有項目**（尤其保留 `docs/` 資料夾）拖到上傳區。上傳後在 `Settings → Pages` 選擇 `Deploy from a branch`、分支 `main`、資料夾 `/docs`，按 `Save`。

注意：網頁版上傳不會保留原本的本地Git提交歷史。本包以公開展示用途為主；完整技術原始碼、Python測試工具與歷史紀錄仍在先前的完整版專案ZIP中。
