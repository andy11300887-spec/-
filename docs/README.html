旅日手帖｜日本自由行入門 LLM Wiki（完成整理版）

繁體中文教學專題，來源查核：2026-11-21。主要讀者：第一次自行安排赴日旅行的人。

最簡單的開啟方式

  1. 解壓縮整個ZIP壓縮檔，保持資料夾結構不變。
  2. 用Chrome或Edge雙擊專案根目錄的 index.html，這是六項作業要求的成果總覽。
  3. 點「開始看12頁教學簡報」，或直接開 slides/deck.html。可用左右鍵、側欄或下方按鈕切換；試算器可輸入自訂金額，測驗可立即作答。
  4. 需要核對內容時查看wiki/index.md、evidence/final_check_report.md和workflow/graph.md。若瀏覽器不展示Markdown，請用VS Code、Antigravity或記事本開啟。

整個教學簡報的CSS與JavaScript都在HTML檔案內，不依賴外部CDN或付費API。Wiki官網連結需要網路才能開啟。

作業內容

  • Wiki：6篇JNTO官方主題頁；每篇均有來源摘要、完整教學、概念頁，共18份正式Wiki頁。
  • 資料取得：sources/registry.csv、proposals/與wiki/log.md。
  • Graph/Loop：workflow/graph.md與workflow/loop.md，包括節點退回與3輪上限。
  • HTML：index.html成果總覽、slides/deck.html十二頁互動簡報。
  • 證據與反思：evidence/final_check_report.md與slides/report.md；附瀏覽器截圖。
  • Git：包含.git歷史，可查看版本變更。

本地重新驗證（安裝Python與Playwright時）

python workflow/run_workflow.py
python tests/lint_wiki.py
python tests/query_wiki.py
python tests/check_slides.py

最後一項使用Chromium及Python Playwright。若電腦未安裝Playwright或Chromium，仍可直接開啟HTML簡報，不影響一般觀看與操作。

非常重要：驗收界線

S001有單篇明確批准，S002–S006由使用者後續的「先完成」指示一次性授權，沒有逐篇單獨審查紀錄。這是和最初規格中「逐篇人工核准」不同的地方，已在每篇提案中註明。

本地Lint、Query與瀏覽器測試都已實際執行；但獨立新對話AI忠實度審查尚未執行。任何即時票價、簽證或特殊交通使用條件都必須在實際旅行前以官方權責網站再確認。
