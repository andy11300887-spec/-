Ingest狀態： 待使用者批准，0篇正式Ingest

A. 已由官方頁面確認的可用主題（不是最終Wiki稿）

  1. 語言：頁面將日文與遊客語言需求列為新手基本資訊。
  2. 時區：介紹日本採單一時區，沒有夏令時間。
  3. 網路：列有Wi-Fi與連線項目，實際服務細節應點開官方子頁查核。
  4. 電源：列有插座與電力主題，攜帶設備前應檢查插頭與電壓規格。
  5. 貨幣：介紹日圓及兌換/付款等基礎概念。
  6. 旅行前查詢：連至天氣、簽證、海關、緊急支援等資訊入口。

上述只是可見主題與保守摘要，不是逐字複製的原頁。原頁入口含會隨時間變化的規定，不應把它當成今日通行條件或費率的唯一權威來源。

B. 需要保留「待確認」或排除的內容

  • 特定國籍的簽證/免簽條件、停留日數：需查日本外務省等權責來源，不可從入口頁推論。
  • 免稅與出境稅等涉及年度變動的詳細金額：本篇不列具體數字，後續另依權責機關資料核實。
  • Wi-Fi服務、漫遊費率與可用範圍：不得把「有Wi-Fi」說成「所有地方都免費」。
  • 信用卡普及程度：應避免寫成「日本所有地方都可刷卡」。
  • 全部官方子連結內容：未逐頁審核前不可當作已Ingest資料。

D. 建議的教學頁架構（非正式內容）

  1. 第一次赴日前先整理四類資訊：旅行條件、連線、付款、環境。
  2. 語言與時區的基本認識（只講官方頁可確認的範圍）。
  3. 網路連線、設備插座、日圓的準備思路。
  4. 動態資訊如何回到權責機關確認。
  5. 示例：出發前一週的自我檢查清單（標示為「示例」）。
  6. FAQ、注意事項、來源和相關知識連結。
