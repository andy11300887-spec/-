來源明載：核對摘要

  1. 基本態度：JNTO建議尊重接觸到的人與地方；不確定當地做法時可禮貌詢問。
  2. 招呼：鞠躬是日本文化中的問候方式，旅客可用禮貌表達感謝，無須預設複雜的商務禮節。
  3. 公共交通：在公共運輸等場合注意音量，手機使用靜音並避免在車廂內通話。
  4. 餐廳：不習慣使用筷子可以禮貌詢問其他餐具，但不一定有提供。
  5. 住宿：傳統旅館可能有脫鞋、浴衣與公共浴場規則，依業者現場說明詢問。

來源界線與待確認
